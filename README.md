# ✨ Glass MP3 – YouTube Downloader

Ein extrem schneller, puristischer und werbefreier YouTube-zu-MP3-Downloader im Glassmorphism-Design.

---

## 🚀 Schnellstart

### 1. Server starten (1-Klick Auto-Setup)
Öffne den Ordner `server` und mache einen **Doppelklick auf `start.bat`**.
* Das Skript prüft automatisch, ob **Python**, **FFmpeg** und **yt-dlp** vorhanden sind, und installiert sie bei Bedarf selbstständig über Windows WinGet.
* Lasse das kleine Konsolenfenster einfach minimiert im Hintergrund offen.

---

### 2. Chrome-Extension aktivieren (einmalig)
1. Öffne Google Chrome und gehe auf: `chrome://extensions`
2. Aktiviere oben rechts den Schalter **„Entwicklermodus“** (Developer mode).
3. Klicke oben links auf **„Entpackte Erweiterung laden“** (Load unpacked).
4. Wähle den Ordner **`extension`** aus.
5. Klicke in Chrome auf das Puzzle-Symbol oben rechts und hefte **Glass MP3** fest.

---

## 🎧 Bedienung
1. Öffne auf YouTube ein beliebiges Video.
2. Klicke auf das **Glass MP3**-Icon oben rechts.
3. Klicke auf die Glass-Kapsel **„MP3 herunterladen“**.
4. Die fertige Datei liegt nach wenigen Sekunden direkt in deinem **Downloads**-Ordner!
